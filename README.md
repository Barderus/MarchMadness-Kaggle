# March Madness Prediction — Kaggle Competition

A collaborative machine learning project developed for Kaggle's March Machine Learning Mania competition, focused on predicting NCAA basketball tournament outcomes using historical game data, statistical feature engineering, and classification models.

## Project Overview

The goal of the competition was to predict the probability of one team defeating another in the NCAA March Madness tournament.

Our team developed a predictive modeling workflow using historical regular-season and tournament data, exploring how team performance, rankings, and statistical differences between opponents could help predict game outcomes.

The project involved:

- **Exploratory Data Analysis:** Investigating historical NCAA basketball statistics, team performance, and tournament results.
- **Feature Engineering:** Creating team-level and matchup features, including team ratings and strength-of-schedule measures.
- **Predictive Modeling:** Training and comparing classification models, including Random Forest and XGBoost.
- **Model Optimization:** Hyperparameter tuning and feature importance analysis.
- **Competition Submission:** Generating matchup probabilities for Kaggle evaluation.

## Methodology

We began by exploring historical basketball data and engineering features that represented team performance throughout the regular season.

These features were combined into historical tournament matchup datasets, allowing classification models to learn relationships between opposing teams' statistics and game outcomes.

We experimented with multiple modeling approaches, compared their performance, and tuned selected models before generating our final competition predictions.

The project also explored the **Massey rating method** for estimating team strength and strength of schedule using historical game results.
